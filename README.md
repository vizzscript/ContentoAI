# ContentoAI ✨
**The Next-Gen AI-Powered Headless CMS**

ContentoAI is a premium, distraction-free authoring platform designed for modern storytellers. It leverages Google Gemini AI to streamline content creation while maintaining a stunning, high-end aesthetic.

---

## 🌟 Key Features

*   **🧠 Intelligent AI Engine**: Sequential AI generation for SEO titles and structured summaries using Google Gemini.
*   **🎨 Premium Aesthetic Editor**: A glassmorphic, distraction-free writing experience with ultra-smooth micro-interactions.
*   **🚀 Public Deployment Pipeline**: A professional workflow to publish articles with one click and preview them on a dedicated public URL.
*   **🛡️ Secure & Scalable**: JWT-based authentication, RBAC, and MongoDB persistence.

---

## 🛠️ Tech Stack

*   **Frontend & Backend**: [Next.js](https://nextjs.org/) (App Router)
*   **Database**: [MongoDB](https://www.mongodb.com/) with [Mongoose](https://mongoosejs.com/)
*   **AI Engine**: [Google Generative AI](https://ai.google.dev/) (Gemini Flash)
*   **Styling**: Vanilla CSS & [TailwindCSS](https://tailwindcss.com/)
*   **Authentication**: JSON Web Tokens (JWT)

---

## ⚡ Quick Start

### 1. Prerequisites
- Node.js (v18+)
- MongoDB
- Google Gemini API Key

### 2. Environment Setup
Create a `.env.local` file based on `.env.example`:
```env
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_gemini_key
```

### 3. Installation & Run
```bash
npm install
npm run dev
```
