# ContentoAI ✨
**The Next-Gen AI-Powered Headless CMS**

ContentoAI is a premium, distraction-free authoring platform designed for modern storytellers. It seamlessly integrates Google Gemini AI to turbocharge your content flow while maintaining a stunning, high-end aesthetic.

---

## 🌟 Key Features

### 🧠 Intelligent AI Engine
*   **Sequential AI Generation**: Real-time typing animations for SEO titles and structured summaries.
*   **Accept/Reject Controls**: Review AI suggestions before merging them into your main content.
*   **Content Awareness**: AI understands your text depth and provides tailored optimizations.

### 🎨 Premium Aesthetic Editor
*   **Glassmorphism UI**: Beautiful semi-transparent layers with backdrop blurs.
*   **Shaded Depth Design**: Ultra-soft, rounded containers (`2.5rem` radius) that fade elegantly into the dark theme.
*   **Dynamic Canvas**: Fully responsive editors that expand as you type, providing an infinite writing experience.
*   **Custom Micro-Interactions**: Aesthetic status dropdowns with glowing state indicators (Draft vs. Published).

### 🚀 Public Deployment Pipeline
*   **Draft to Live**: A clear, professional deployment workflow—only public when you're ready.
*   **Instant Live View**: Successive deployment allows you to preview your live article instantly at a dedicated public URL.
*   **Public Reader Mode**: A distraction-free, typography-focused reading interface for your audience.

### 🛡️ Robust Infrastructure
*   **Secure Authentication**: JWT-based security with Role-Based Access Control (RBAC).
*   **Toast Notification System**: A centralized, sleek error/success notification system.
*   **Performance First**: Built with Next.js App Router and MongoDB for lightning-fast speeds.

---

## 🛠️ Tech Stack
*   **Frontend**: Next.js 15, React, TailwindCSS
*   **Backend**: Next.js API Routes, MongoDB
*   **AI**: Google Generative AI (Gemini Flash)
*   **Auth**: JWT (JSON Web Tokens)
*   **Styling**: Vanilla CSS + Tailwind Glassmorphism Utilities

## ⚡ Quick Start

### 1. Prerequisites
Ensure you have Node.js and MongoDB installed, along with a Gemini API Key.

### 2. Environment Setup
Create a `.env` file in the root directory:
```env
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_gemini_key
```

### 3. Installation
```bash
npm install
npm run dev
```

---

## 📸 Deployment Workflow
1.  **Write**: Start your story in the premium editor.
2.  **Enhance**: Use "AI Insights" to generate summaries and SEO titles.
3.  **Deploy**: Select "Published" and hit the gradient **Deploy Article** button.
4.  **Preview**: Click **🌍 View Live** to see your content live!
